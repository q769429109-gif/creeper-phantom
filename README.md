# 杂交苦力怕 Hybrid Creeper

> Minecraft **1.21.1** · **NeoForge** · MIT · **v1.0**

给世界加入 **两只会上门索命的爆炸系敌对生物**：天上盯你的**苦力怕幻翼**，水里追你的**苦力怕海豚**。

两只都能像原版苦力怕一样**被闪电充能**——充能后爆炸威力翻倍。

**原版内容一个字节都不改**：不修改任何原版生物、物品或生成规则，只是往世界里加东西。

## 安装

| 要求 | 版本 |
| --- | --- |
| Minecraft | **1.21.1** |
| NeoForge | **21.1.0** 或更高（21.1.x 系列任意版本，实测 21.1.248 正常） |
| Java | 21 |
| 多人服务器 | **客户端也必须安装**（有自定义实体与模型） |

1. 安装 NeoForge 1.21.1（客户端 / 服务端）；
2. 把 `hybridcreeper-1.0.jar` 放进 `mods/` 文件夹；
3. 启动游戏。

首次进入世界后会自动生成配置文件 `config/hybridcreeper-common.toml`（见[配置](#配置)）。

> **卸载**：删掉 jar 即可，原版不留任何痕迹。已刷在地图里的这两只生物会变成「未知实体」并消失，属正常现象。

## 生物一 · 苦力怕幻翼

> `hybridcreeper:creeperphantom` ・ Creeper Phantom

一只**会俯冲自爆**的幻翼。外观、手感、叫声都和原版幻翼一样（血量 20、怕猫、会被阳光点燃、和平模式消失）——**区别只在它咬中你的那一瞬间**。

|  | 原版幻翼 | 苦力怕幻翼 |
| --- | --- | --- |
| 俯冲击中玩家 | 撕咬伤害 | 撕咬伤害 **＋ 苦力怕等级的爆炸** |
| 掉落物 | 幻翼膜 | 幻翼膜 **＋ 火药**（0~2 个，吃抢夺） |
| 什么时候出现 | 要你**连续 3 个游戏日不睡觉** | **入夜就来**，与你睡不睡觉无关 |

> ### ⚠️ 默认参数下基本必死
>
> 被咬中会同时吃到 `撕咬伤害` 和 `贴脸爆炸伤害（约 49 点）`，**穿钻石套也活不下来**。
>
> 觉得太狠：把配置里的 `hitPlayerDamageMultiplier` 调到 `0.4` 左右 —— 见[配置](#配置)。

**它怎么出现：** 和僵尸一样走标准的怪物刷新——**夜晚或阴暗处、主世界的地表**，生成后起飞盘旋。所以它来得比原版幻翼勤快得多；而**原版幻翼该怎么来还是怎么来**（仍要求你熬满 3 天不睡觉，本模组不干预它）。

**原版幻翼完全不受影响**，两只可以在同一个世界里共存。

### 怎么把它叫出来

```
/summon hybridcreeper:creeperphantom ~ ~10 ~
```

创造模式物品栏里也有 **苦力怕幻翼刷怪蛋**。

想现场看它俯冲：`/time set midnight`，站到开阔地等它盘旋几轮——它会先嘶吼一声，然后冲下来。

## 生物二 · 苦力怕海豚

> `hybridcreeper:water_creeper` ・ Creeper Dolphin

一只专门在水里猎杀你的生物：海豚的身子和游速，苦力怕的躯干、脑袋和四条腿（**专属模型与贴图**）。

| 特性 | 说明 |
| --- | --- |
| **出现地点** | **任何有水的地方** —— 海洋、河流、湖泊、池塘、沼泽，甚至 **1 格深的小水坑** |
| **出现时段** | **全天**（不看光照，白天照样刷） |
| **游动速度** | **很快** —— 光靠游泳甩不掉它，想拉开距离得用船 |
| **撞船** | 高速撞向船上的你，造成伤害、把船撞偏、打断你的行动 |
| **贴身自爆** | 贴上后开始膨胀，约 **1.5 秒** 后爆炸（机制与苦力怕相同） |
| **上岸追击** | 你躲到岸上，它会**跳出水面扑上来**，落地立即引爆 |
| **⚡ 闪电充能** | 被雷劈中后爆炸半径翻倍（3.0 → 6.0） |

### 怎么对付它

**往高处跑。** 它跳不了太高（约 1.5 格）——站在悬崖或有落差的高岸上就是安全的。

### 怎么把它叫出来

```
/summon hybridcreeper:water_creeper ~ ~ ~
```

创造模式物品栏里也有 **苦力怕海豚刷怪蛋**。

想看完整表演：找一片海 → `/time set midnight` → 划船在水面飘着（它会撞船）→ 跳下水（它会膨胀）→ 逃上岸（它会扑上来）。

## ⚡ 闪电充能

**两只生物都能被闪电劈成「充能」状态**，机制完全照搬原版苦力怕：

| | 普通 | 闪电充能 |
| --- | --- | --- |
| 爆炸半径 | `3.0` | **`6.0`**（翻倍） |

被劈中后会裹上一层**滚动的蓝色能量**（就是充能苦力怕身上那层），大老远就能认出来。

**充能是永久的**——劈过一次就一直是充能状态，淋雨、泡水、睡觉都不会掉。

### 什么闪电都算

- 雷雨天自然落雷劈中它们；
- **引雷（Channeling）附魔的三叉戟**掷中它们（投掷时需要下雨）；
- 指令 `/summon lightning_bolt ~ ~ ~`。

> 苦力怕海豚**在水里也能被劈中**（原版闪电判定不过滤水中），只是身上的火会立刻被水浇灭，实际剩「充能 + 雷电伤害」。

> ⚠️ **充能后威力 6.0，开着破坏方块时一发能掀掉一栋木屋。** 测试前建议先把 `destroyBlocks` 改成 `false`。

## 配置

文件：`config/hybridcreeper-common.toml`（首次启动自动生成）。

### 常用改法

| 想要的效果 | 改哪一项 |
| --- | --- |
| **太容易死了，想活下来** | `hitPlayerDamageMultiplier = 0.4` |
| 保护建筑，只炸人不炸地形 | `destroyBlocks = false` |
| 爆炸威力更大（像 TNT） | `explosionPower = 4.0` |
| 关掉爆炸，只保留生物 | `[general] enabled = false` |
| 幻翼别自然刷出来 | `[spawn] naturalSpawn = false` |
| **海豚别自爆，只撞船** | `[waterCreeper] explode = false` |
| **海豚太快 / 太慢** | `[waterCreeper.attributes] swimSpeed`（默认 7.5） |
| **海豚别跳上岸扑人** | `[waterCreeper.ai] beachAssault = false` |
| **给海豚更多逃跑时间** | `[waterCreeper.explosion] fuseTicks = 60`（3 秒） |
| 一只海豚都别刷 | `[waterCreeper] naturalSpawn = false` |

### 完整选项

```toml
[general]
    # 总开关。false 时苦力怕幻翼只俯冲撕咬，不爆炸。
    # 注意：这个开关不影响原版幻翼 —— 它从头到尾都没被改过。
    enabled = true

[explosion]
    # 爆炸威力（= 半径）。原版苦力怕 = 3.0，TNT = 4.0。
    explosionPower = 3.0
    # 是否破坏方块。false = 只炸实体，地形完好。
    destroyBlocks = true
    # 爆炸是否引燃周围方块。原版苦力怕不引燃。
    setFire = false
    # 苦力怕幻翼是否免疫自己引发的爆炸。
    phantomImmune = true

[damage]
    # 爆炸对所有实体的伤害倍率。
    damageMultiplier = 1.0
    # 额外作用于「被咬中的那名玩家」的伤害倍率（想活命就调它）。
    hitPlayerDamageMultiplier = 1.0
    # 同一只生物两次引爆的最小间隔（tick，20 tick = 1 秒）。
    cooldownTicks = 40

[spawn]
    # 苦力怕幻翼是否自然生成。false = 只能用指令 /summon 或刷怪蛋。
    naturalSpawn = true

[debug]
    # 开启后日志里会打印每次引爆的坐标，用来排查「到底有没有触发」。
    debugLog = false

[waterCreeper]
    explode = true
    naturalSpawn = true

    [waterCreeper.attributes]
        maxHealth = 20.0             # 最大生命
        attackDamage = 4.0           # 撞击伤害（爆炸另算）
        movementSpeed = 1.5          # 陆地上（含上岸突袭）的移速
        swimSpeed = 7.5              # 水中的速度倍率（水里速度 = 0.02 × 本值）
        followRange = 32.0           # 主动索敌距离
        knockbackResistance = 0.3    # 抗击退

    [waterCreeper.explosion]
        explosionPower = 3.0         # 爆炸威力（= 半径）
        destroyBlocks = true         # 是否破坏方块
        setFire = false              # 是否引燃
        damageMultiplier = 1.0       # 爆炸伤害倍率
        fuseTicks = 30               # 引信长度（20 tick = 1 秒）
        chargedMultiplier = 2.0      # 被闪电充能后的半径倍率

    [waterCreeper.ai]
        swellRange = 3.0             # 贴到几格内开始点燃引信
        beachAssault = true          # 是否允许跳出水面扑上岸

    [waterCreeper.ram]
        cooldownTicks = 16           # 两次撞船之间的最小间隔
```

> ### 两只生物的参数是分开的
>
> - `[general]` / `[explosion]` / `[damage]` / `[spawn]` 这几段**只作用于苦力怕幻翼**。
> - **苦力怕海豚的全部参数都在 `[waterCreeper]` 段**（共 17 项，见上）。
>
> ⚠️ 配置数值是在生物**生成时**写进它的属性和实体数据里的（和原版苦力怕一样）。
> 所以：**改完配置，新刷出的立刻生效**；已经存在于世界里的旧生物保留自己的数值，
> 等它们消失或重新刷出后才变。想单独改某一只：
> `/data merge entity <目标> {Fuse:60,ExplosionRadius:5}`。

## 注意事项 / 常见问题

- **多人服务器必须让客户端也安装本模组** —— 有自定义实体与模型，否则连不上服务器。
- **创造模式不会触发爆炸** —— 原版对创造模式玩家本来就不结算伤害。
- **举盾完全格挡时不爆炸** —— 伤害被盾牌压成 0，判定为「没咬中」。
- **下界和末地不会自然生成** —— 两只都只在主世界出现。
- **幻翼刷不出来的常见原因**：它和僵尸共用「怪物总量上限」。
  如果你周围已经堆了一大堆僵尸骷髅（上限约 70 只），**所有怪物都会停止刷新**，
  清一波怪就回来了。
- **海豚在任何水域都会出现**，包括你家门口 1 格深的小水坑 —— 这是设计如此。
  想让它只在海里刷，需要改数据包；想彻底关掉就用 `[waterCreeper] naturalSpawn = false`。
- **原版内容零改动**，所以与本模组冲突的概率极低。
