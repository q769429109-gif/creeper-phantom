## 🎮 这个版本有什么

给游戏加入 **两只会上门索命的爆炸系敌对生物**。原版内容一个字节都不改。

### 🟢 苦力怕幻翼 · `hybridcreeper:creeperphantom`

一只会俯冲自爆的幻翼。

血量、攻击力、跟随范围、命中箱、叫声、幻翼膜掉落、怕猫、被阳光点燃、和平模式消失 ——
**一切与原版幻翼完全相同**，连出现方式都一样（夜晚 + 连续 3 个游戏日不睡）。

**唯一的区别在它咬中你的那一瞬间：引爆一个苦力怕等级的爆炸。**

> ⚠️ **默认参数下基本必死。**
> 被咬中会同时吃到 `撕咬伤害（6 + 体型）` 和 `近距离爆炸伤害（约 49 点）`，
> 穿钻石套也活不下来。
>
> 觉得太狠，把配置文件里的 `hitPlayerDamageMultiplier` 调到 `0.4` 左右。

**原版幻翼完全不受影响**，两只可以共存于同一个世界。

### 🔵 水下苦力怕 · `hybridcreeper:water_creeper`

一只专门在水里猎杀玩家的生物。

| 特性 | 说明 |
| --- | --- |
| **出现地点** | 海洋与河流的水下，阴暗环境（夜晚或深水） |
| **游动速度** | **比船还快** —— 在水里单纯逃跑是没用的 |
| **撞击船** | 高速撞向船上的你，造成伤害并把船撞偏，打断你的行动 |
| **膨胀自爆** | 贴身后开始膨胀，约 1.5 秒后爆炸（机制与苦力怕相同） |
| **上岸追击** | 你躲到岸边，它会**跳出水面扑上来**，落地立即引爆 |

**怎么对付它：往高处跑。** 它的跳跃高度有限（约 1.5 格），站在悬崖或有落差的高岸上就是安全的。

## 🔧 安装

1. 装好 NeoForge 1.21.1 的客户端 / 服务端；
2. 把本页下载的 jar 放进 `mods/` 文件夹；
3. 启动游戏。

首次进入世界后会自动生成配置文件 `config/hybridcreeper-common.toml`。

**卸载**：删掉 jar 就行，原版内容没有任何痕迹。

---

## ⚙️ 配置速查

| 想要的效果 | 改哪一项 |
| --- | --- |
| 保护建筑，只炸人不炸地形 | `destroyBlocks = false` |
| 太致命了，想能活下来 | `hitPlayerDamageMultiplier = 0.4` |
| 只惩罚周围的怪，不额外伤害被咬的人 | `hitPlayerDamageMultiplier = 0.0` |
| 更猛一点，像 TNT | `explosionPower = 4.0` |
| 自爆后同归于尽 | `phantomImmune = false` |
| 关掉爆炸，只保留生物 | `enabled = false` |
| 压根不想让它自然刷出来 | `naturalSpawn = false` |
| 想让它更容易出现 | `minTicksSinceRest = 24000`（3 个游戏日 → 1 个） |
| 看不出到底有没有触发 | `debugLog = true`，日志里会打坐标 |

完整选项说明见 README 的「配置」章节。

## ⚠️ 注意事项

- **多人服务器必须让客户端也安装** —— 本模组有自定义模型与自定义实体，客户端不装会连不上服务器。
- **创造模式不会触发爆炸** —— 原版对创造模式玩家本来就不结算伤害。
- **举盾完全格挡时不爆炸** —— 伤害被盾牌压成 0，判定为「没咬中」。
- **下界与末地不会自然生成** —— 与原版幻翼一致，只在主世界。
- **原版内容零改动** —— 只是新增内容，与其他模组几乎不会冲突。

### 已知问题

- **水下苦力怕的模型暂时借用原版海豚**（命中箱 0.9 × 0.6 也跟着走），后续会替换成专属模型。
- **水下苦力怕的爆炸参数写死在代码里**（半径 3、引信 1.5 秒），
  配置文件里 `[explosion]` 那一段**对它不生效** —— 只作用于苦力怕幻翼。

## 🚨 从开发版升级

如果你之前装过开发期的 `phantomblast` 版本，请注意**模组 ID 已经改名**：

```
phantomblast:creeperphantom  →  hybridcreeper:creeperphantom
phantomblast:water_creeper   →  hybridcreeper:water_creeper
```

世界里的旧生物会变成「未知实体」并消失。删掉旧 jar 换上新 jar 即可，没有其他需要处理的事项。
配置文件也会重新生成为 `config/hybridcreeper-common.toml`。
